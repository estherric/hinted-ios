# HINTED

**Your outfit, your vibe.**

HINTED is an iOS mobile application developed using Swift and SwiftUI that helps users create outfits based on current weather conditions and their personal style or mood.

## Project Overview

Choosing an outfit can be time-consuming, especially when considering the weather and personal preferences. HINTED aims to simplify this process by providing personalized outfit suggestions using clothing items from the user's virtual closet.

## Key Features

The following features are planned for the application:

- **Weather-Based Recommendations:** Suggest outfits based on local weather conditions.
- **Vibe-Based Outfit Selection:** Allow users to choose a style or mood to influence outfit recommendations.
- **Virtual Closet:** Add, organize, and manage clothing items.
- **Outfit Generator:** Create outfit combinations using clothing from the user's closet.
- **Saved Looks:** Save favorite outfit combinations for future use.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/estherric/hinted-ios.git
   ```

2. Open `Hinted.xcodeproj` in Xcode.
3. Select an iOS simulator.
4. Build and run the project using `Command + R`.
